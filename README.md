# Hyunjin Ahn



## What I actually do

- **Enterprise portals & culture platforms** — React + TypeScript(strict), Azure AD / MSAL SSO, Entra ID App Roles for RBAC. Unified hubs that stitch HR, approval, mail, and ERP into one surface.
- **Mobile** — React Native (new architecture). Notifee/FCM push, deep linking, enterprise iOS/Android distribution.
- **Backend & data** — Node.js, NestJS / Express, MySQL 8. Raw SQL when the query is the product, Prisma when it isn't.
- **AI integration** — LLM-generated task extraction from mail, RAG over internal knowledge (hybrid FULLTEXT + vector similarity), conversational voice agents.
- **Automation & ops** — n8n workflows, Jenkins pipelines, nginx, Datadog / Sentry.

## Before this

At [Young IT](https://young-it.co.kr/), I built a **remote water-meter reading system** on the **LwM2M** IoT standard — device management, telemetry ingestion, and the operations console.

I also worked on the **image recognition** side of it: reading digits off analog water meter dials from field-captured images, where lighting, dial glare, and half-rotated digits break every assumption a clean dataset gives you.

## Interests

React · TypeScript · MySQL · enterprise architecture · LLM systems

Long-term: contributing something real to **digital twin** infrastructure. The meter-reading work was the first honest step toward it — physical asset, live telemetry, a model that has to stay true to the thing it mirrors.
